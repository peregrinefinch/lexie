# Changelog

## 1.0.0

- Initial release of `lexie`.
- Generate lexers, token classes, spans and optional syntax highlighters from TOML.
- Keep the standalone specification in an ignored `.lexie/lexie.toml`.
- Configure generated directories and choose located lexemes or plain tokens.
- Use Poke for unit, property, regression, generated-code and snapshot tests.
